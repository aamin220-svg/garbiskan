# بوابة أعضاء الجمعية — نظام تسجيل الأعضاء

## الإصدار الحالي
هذا الإصدار يضيف تسجيل العضو مع:
- الاسم رباعي باللغة العربية (4 أسماء بالضبط).
- الإدارة / المنطقة.
- الرقم القومي (14 رقمًا).
- رقم الموبايل.
- البريد الإلكتروني.
- إرسال كود تفعيل حقيقي إلى البريد الإلكتروني.
- بعد إدخال الكود بنجاح يتم حفظ بيانات العضو في جدول `member_profiles` وإظهار رقم ترتيبه من كشف العضوية.

## مطابقة العضوية
المطابقة الحالية مع كشف الأعضاء تتم بالاسم كما هو موجود في `data/members.json`، مع استبعاد أي سجل حالته "منسحب" (إن وُجد).

## بيانات العضو التي يتم حفظها
بعد نجاح التفعيل يتم حفظ:
- رقم العضوية من الكشف
- الاسم
- الإدارة / المنطقة
- الرقم القومي
- رقم الموبايل
- البريد الإلكتروني
- تاريخ ووقت التفعيل

الرقم القومي لا يُخزن كنص ظاهر في الكود أو الواجهة العامة؛ يتم تخزينه في قاعدة البيانات كبيان خاص بالعضو.

## إعداد إرسال البريد الحقيقي
الملف `.env.example` يحتوي على الإعدادات المطلوبة:

```env
PORT=3000
RESEND_API_KEY=ضع_مفتاح_Resend_هنا
FROM_EMAIL=اسم الجمعية <noreply@دومينك.com>
DEV_LOG_CODE=false
```

للاختبار الحقيقي عبر البريد، يجب وضع مفتاح API صحيح من Resend وعنوان إرسال مسموح به من الخدمة. بعدها أي عضو يكتب بريده في نموذج التسجيل سيصل إليه كود مكون من 6 أرقام صالح لمدة 10 دقائق.

> لا تضع مفتاح API داخل `public/index.html` أو أي ملف يصل للزوار.

## التشغيل
```bash
npm install
npm start
```

ثم افتح:
`http://localhost:3000`

## اختبار محلي بدون بريد
يمكن استخدام:
```env
DEV_LOG_CODE=true
```
وسيظهر الكود في Console الخاص بالسيرفر بدل إرساله بالبريد. هذا الخيار للاختبار المحلي فقط، ويجب إيقافه على الموقع الحقيقي.

## ملاحظات مهمة
- الرقم القومي يجب أن يكون 14 رقمًا، ويقبل الأرقام العربية أو الإنجليزية.
- الاسم يجب أن يكون 4 كلمات باللغة العربية.
- لا يمكن تسجيل نفس البريد الإلكتروني أو الرقم القومي أو رقم العضوية أكثر من مرة بعد التفعيل.
- كود التفعيل لا يُخزن كنص صريح؛ يتم تخزين قيمة Hash للكود.
- الكود صالح لمدة 10 دقائق وبحد أقصى 5 محاولات إدخال قبل طلب كود جديد.


## استعادة كلمة المرور وتسجيل الدخول
تمت إضافة:
- رابط «نسيت كلمة المرور؟» في نموذج دخول الأعضاء.
- البحث بالبريد الإلكتروني أو رقم الهاتف.
- إرسال رابط آمن لإعادة تعيين كلمة المرور إلى البريد الإلكتروني المرتبط بالعضو.
- صفحة إعادة تعيين داخل الموقع تطلب البريد الإلكتروني وكلمة المرور الجديدة مرتين.
- تسجيل الدخول تلقائيًا بعد نجاح إعادة التعيين.
- تسجيل الدخول بالبريد الإلكتروني أو رقم الهاتف بعد إنشاء كلمة المرور.
- روابط إعادة التعيين صالحة لمدة 30 دقيقة وتُحفظ في قاعدة البيانات على هيئة Hash.
- لإرسال الروابط فعليًا، اضبط `RESEND_API_KEY` و`FROM_EMAIL` و`PUBLIC_URL` في `.env`.

## الطلبات والمراسلات وبيانات العضوية
- خدمة «بيانات العضوية» لا تعرض البيانات إلا بعد وجود جلسة دخول صالحة، وإلا تظهر رسالة «برجاء تسجيل الدخول». رقم العضوية مأخوذ من كشف العضوية `data/members.json`.
- خدمة «الطلبات والمراسلات» تتطلب تسجيل الدخول، وتعرض تلقائيًا اسم العضو ورقم العضوية ورقم الموبايل والإدارة والرقم القومي، مع خانة رسالة كبيرة وإرسال.
- الطلبات تحفظ في SQLite داخل جدول `member_requests` ويمكن لإدارة الجمعية البحث فيها من صفحة `/admin.html` باستخدام `ADMIN_KEY`.
- يتم إرجاع «الإيميل غير مسجل لدينا.» عند إدخال بريد غير موجود في نظام إعادة تعيين كلمة المرور أو تسجيل الدخول.
- تم حذف خدمة نقل الملكية/الورثة من واجهة الموقع.

### إعداد إدارة الطلبات
أضف في `.env`:
`ADMIN_KEY=مفتاح-قوي-خاص-بالإدارة`
ثم افتح `/admin.html` وأدخل المفتاح للبحث ومراجعة الطلبات وتغيير حالتها وإضافة ملاحظات الإدارة.
